PENYEMPURNAAN SEO DAN KECEPATAN — MANDALA AKSARA

Isi pembaruan:
1. Metadata SEO (deskripsi, canonical, Open Graph, dan Twitter Card) pada halaman publik.
2. sitemap.xml diperluas ke seluruh 107 halaman publik.
3. robots.txt ditambahkan dan menunjuk ke sitemap.
4. Logo dan empat gambar sampul dikonversi ke WebP; referensi HTML diarahkan ke WebP.
5. Gambar konten menggunakan lazy loading dan decoding async; script.js menggunakan defer.

CARA PEMASANGAN:
- Cadangkan repositori sebelum mengganti berkas.
- Ekstrak ZIP ini, lalu unggah berkas-berkasnya ke repositori GitHub dengan mempertahankan nama berkas.
- Tambahkan robots.txt dan berkas WebP baru. Timpa sitemap.xml serta halaman HTML yang diperbarui.
- Jangan hapus PNG lama dulu. Setelah semua halaman diperiksa dan gambar WebP tampil normal, file PNG lama dapat dihapus secara terpisah untuk mengurangi ukuran repositori.

CATATAN YANG MASIH PERLU DITINDAKLANJUTI:
- Dua gambar berikut belum tersedia dalam arsip sumber: ilustrasi-teks-negosiasi.jpg dan anekdot-ilustrasi.jpg. Halaman yang memanggilnya perlu diberi aset yang benar atau referensinya diperbaiki.
- Metadata dan sitemap sudah diperiksa secara lokal, tetapi hasil indeks Google dan skor PageSpeed baru dapat dinilai setelah perubahan dipublikasikan.
- Google Analytics dan file verifikasi Google tidak diubah.
