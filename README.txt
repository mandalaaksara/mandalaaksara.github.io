MANDALA AKSARA — STARTER WEBSITE

Isi:
- index.html: halaman beranda
- style.css: tampilan responsif
- script.js: navigasi seluler dan pencarian awal
- assets/: logo dan gambar hero

Catatan:
Ini adalah prototipe awal halaman Beranda. Tautan menu selain Beranda masih berupa halaman tujuan yang akan kita buat pada tahap berikutnya. Fungsi pencarian dan kelas virtual belum terhubung ke katalog atau layanan eksternal.
Untuk GitHub Pages, unggah seluruh isi folder ini ke root repositori dan aktifkan Pages dari Settings > Pages.
